## About the Game

Swami Formula is a compact motorsport career simulation focused on the rise of a driver you create. Define the driver's nationality, livery, race number, balance, and racing trait before choosing an academy seat and shaping the seasons that follow.

Race outcomes are influenced by weather, reliability, and decisions whose results may not be immediate. Track attributes, reputation, championship standings, points, wins, and podiums throughout the career. Because simulations use seeds, the same setup can be replayed for consistent comparisons.

## Key Features

- Create a personalized driver for career mode.
- Configure nationality, livery, race number, balance, and racing trait.
- Pick from the academy team seats that are available.
- Play through simulated seasons affected by weather changes and mechanical reliability.
- Make decisions that can produce consequences later in the career.
- Monitor attributes, reputation, standings, points, victories, and podium finishes.
- Re-run comparable scenarios with seeded careers.
- Save and resume progress through browser `localStorage`.

## Playing Swami Formula

1. Open the standalone HTML file in a web browser.
2. Create a driver and set the available identity and racing preferences.
3. Choose an academy team seat.
4. Progress through races and respond to decisions when they appear.
5. Inspect season results, reputation, standings, points, wins, and podium totals.
6. Reopen the game in the same browser later to resume the saved career.

To compare repeat playthroughs, start simulations with the same career seed.

## Save Data and Configuration

Career data is kept in the browser's `localStorage`. As a result, progress can persist between sessions without an account or a server-side service.

Clearing browser site data may delete the saved career. To continue an existing run, use the same browser profile and avoid removing its stored data.

## Frequently Asked Questions

### Does Swami Formula run in a browser?

Yes. The game works in a web browser and may also be opened locally from its standalone HTML file.

### Is any installation required?

No. You can use the standalone build without installing packages or starting a local server.

### Where does the game store my career?

The current browser profile stores progress in its `localStorage`.

### Are career situations replayable?

Yes. Using the same seed and choices is intended to produce repeatable results.

### Are light and dark modes available?

Yes. The game provides both light and dark themes.

### Why has my saved progress vanished?

Confirm that you are using the original browser profile and that its site data has not been cleared. Private browsing and browser storage settings can also prevent progress from being retained.
